Privacy Policy

Moonlit Japan Studio Tools · Last updated: October 18, 2026

1. What this tool is

Moonlit Japan Studio Tools ("the tool") is a private, internal command-line tool. It is used only by the owner of the YouTube channel Moonlit Japan to manage that channel. It is not available to the public.

2. YouTube API Services

The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. Information accessed through YouTube API Services is also subject to the Google Privacy Policy.

3. Information the tool accesses

With the channel owner's permission (Google OAuth), the tool accesses only the Moonlit Japan channel's own data:

  • the channel's own videos, playlists, captions and thumbnails (to upload, schedule and update them);
  • the channel's own YouTube Analytics reports (views, watch time, audience retention, subscribers gained).

The tool does not access other users' channels or private information, does not read or store comments, and does not use device information, cookies or tracking.

4. How the information is used

The information is used only to publish and manage Moonlit Japan's own videos and to decide which topics to make next.

5. Storage, sharing and deletion

  • The OAuth token and analytics reports are stored only on the channel owner's own computer.
  • Nothing is sold or shared with third parties.
  • Data obtained from the YouTube API is refreshed or deleted within 30 days, except the channel's own aggregated statistics. Those are kept for up to 36 months for comparison.
  • To delete stored data, the channel owner deletes the local token and report files. Access can also be revoked at any time on the Google security settings page (third-party access).

6. Contact

Questions about this policy can be sent through the Moonlit Japan YouTube channel: youtube.com/channel/UCGdZVKjL4KX37ruftSRHZDw.
